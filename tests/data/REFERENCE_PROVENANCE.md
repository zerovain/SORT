# Numerical reference contract

`tiny_cpu_reference.npz` is the original end-to-end fixture and is retained
unchanged. Its exact KNN graph and automatic-SVD output are platform-dependent:
the regular grid contains distance ties, and LAPACK/ARPACK implementations can
choose different singular-vector signs or subspaces. It is not a portable
bitwise test of the optimizer.

`tiny_optimizer_reference_v2.npz` was generated by the unchanged retained
manuscript implementation, not by the candidate release being tested. The
embedded `provenance_json` records the original input hash, source hashes,
software versions and seed. Both the graph and initial W/Q are included.

The regression tests the two-stage CPU optimizer with fixed inputs at float32
precision (`rtol=2e-5`, `atol=2e-6`). This tolerance does not absorb changed
graphs or different initializations. Graph assembly and seeded initialization
are tested separately. It is not a claim of bitwise CPU/GPU identity.
