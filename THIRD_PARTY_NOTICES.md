# Third-party software and data

No third-party package source or biological dataset is vendored in this
repository. Python dependencies and tested versions are listed in
`pyproject.toml` and `environment.yml` and remain subject to their respective
licenses.

Tutorial inputs are derived from external public datasets or from the released
simulation workflow. The original repositories, accessions, licenses, and
usage restrictions continue to apply. See `docs/DATA_AVAILABILITY.md`.
