# Simulation seed 0003

`seed_0003.h5ad` is the complete author-generated input used by the simulated
atlas tutorial: 10,368 locations from eight sections and the 5,000 genes
supplied to SORT. It contains sparse uint16 counts in `.X`, spatial coordinates,
section metadata, aligned spatial and gene-signature truth, and the exact
per-section spatial Laplacian. It contains no fitted SORT matrices or
reconstructed expression. Seed 0003 is the representative simulation used for
the spatial panels in Fig. 2a--d; the 20-seed benchmark remains separate.

SHA-256:
`e52b52fe4bbfaea03e850083e11a44181a967b8e3510b0133007016e96d7413a`.

At approximately 27 MB it is below GitHub's 50 MiB warning threshold and may
be kept with the tutorial source. The same immutable file may also be mirrored
in the versioned Zenodo record.
